Core question

Total value can hide a thin lineup floor.

Star-player value and total Core XI value often describe a team's ceiling. This project asks whether the opposite edge of the lineup, the least expensive starters, is more revealing of group-stage resilience.

Source sensitivity

Manual and Transfermarkt fallback rows did not overturn the broad result.

Excluding Transfermarkt/manual fallback rows removed 32 player values across 15 teams and left 33 complete teams. The weakest-link top-ten overlap was 8/10.

Interpretation

Lineup floor is associated with performance in this sample. It should not be read as a causal model or a standalone prediction engine.
