Methodology

How the lineup-floor metric was built

1. Core XI reconstruction

For each country, I reconstructed its most-used XI from actual group-stage participation. Players were prioritized by minutes, then starts, then appearances, with a deterministic name tie-breaker only if needed. This is a retrospective usage-based XI, not a pre-tournament projected lineup.

2. Player valuation

FootballTransfers was the primary source. FotMob/SciSports was the first fallback. Transfermarkt and manually verified indexed records filled final gaps. Source flags remain in the dataset.

3. Currency conversion

EUR values were converted to USD using the established rate: 1 EUR = 1.1406 USD. Full precision is retained in the CSV files.

4. Weakest-link calculation

Each Core XI was ranked by USD player value. The main metric is the average value of the three lowest-valued players within those 11 players only. It does not use the three cheapest players in the full squad or the cheapest players who appeared for any number of minutes.

5. Results comparison

Lineup-floor value, total Core XI value, top-three average value, and lineup imbalance were compared with group-stage points, group-stage goal difference, group position, and advancement to the knockout stage.

Limitations

  • Mixed valuation providers use different models and update schedules.
  • Fallback-source rows improve coverage but make low-end exact ordering less certain.
  • Core XI is reconstructed from observed tournament usage rather than announced pre-tournament intent.
  • The analysis is associative and descriptive, not causal.
